# Open-Kendo Sliced Benchmark Video Segments

This directory contains short, focused video clips cut from raw reference videos (5–7 minutes) to enable rapid, deterministic model testing, pose estimation, and biomechanics evaluation.

All clips are generated by [`scripts/crop_video_segments.py`](../../scripts/crop_video_segments.py) using frame-accurate H.264 slicing. Complete machine-readable metadata is saved in [`segments_catalog.json`](./segments_catalog.json).

## Usage

To re-cut all segments or add new segments, execute:
```powershell
.\.venv\Scripts\python.exe scripts/crop_video_segments.py
```
Options:
- `--engine`: `auto` (default), `ffmpeg`, or `opencv`.
- `--output-dir`: destination directory (default: `data/segments`).
